# PHP ESP Controller

هذا المشروع عبارة عن نظام تحكم بسيط باستخدام **PHP** للتواصل مع جهاز
**ESP8266 / ESP32** عبر بروتوكول **HTTP** للتحكم في:

* الباب
* النور
* الصوت / الإنذار

يتم إرسال الأوامر من السيرفر للـ ESP مباشرة عبر روابط URL.

---

## 📌 المتطلبات

* PHP 7 أو أعلى
* جهاز ESP8266 أو ESP32
* شبكة WiFi مشتركة بين السيرفر والـ ESP
* عنوان الـ IP الخاص بالـ ESP

---

## ⚙️ شرح طريقة العمل

ملف PHP يقوم بإرسال طلب HTTP إلى الـ ESP بهذا الشكل:

```php
<?php
$esp_ip = "192.168.1.50"; // IP الخاص بالـ ESP
$action = $_GET['action'] ?? '';

if ($action) {
    $url = "http://$esp_ip/control?action=$action";
    $response = file_get_contents($url);

    echo "ESP Response: " . $response;
} else {
    echo "No action provided.";
}
?>
```

---

## 📝 ملاحظات

* يجب أن يكون السيرفر والـ ESP على نفس الشبكة.
* يفضل إضافة حماية (Token أو Password) قبل الاستخدام الحقيقي.
* يمكن إضافة المزيد من الأوامر أو توسيع النظام ليشمل حساسات.
